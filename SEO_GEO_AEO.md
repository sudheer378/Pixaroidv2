# Pixora Discovery Specification

## SEO

Every indexable tool page must have one primary search intent, a stable canonical URL, unique title and description, one clear H1, useful supporting content, appropriate structured data, breadcrumbs, internal links and sitemap eligibility. Thin, duplicate and purely programmatic doorway pages are not part of the strategy.

## GEO

Content should be easy for generative search systems to understand and ground: clear entities, concise factual definitions, explicit capabilities, supported formats, limitations, privacy behavior and contextual links. Claims must match actual product behavior.

## AEO

Important pages should answer natural-language questions directly before expanding into detailed guidance. Question sets are stored with the tool definition so the same source of truth can power UI content, metadata and answer-oriented sections.

## International strategy

Pixora is global by default, with initial market priority for the United States, United Kingdom, Canada, Australia, Germany, France, Spain, Italy, Netherlands and India. Localization will be introduced only when translated/localized content is genuinely useful.

## Measurement

Track search impressions, clicks, CTR, query themes and indexing health through search tooling. Track tool-view, file-selection, processing, completion, failure, download and related-tool events in product analytics. AI-search citation/grounding signals should be added when available from connected search platforms.
